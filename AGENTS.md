# Абсолютна заборона керування без дозволу

- Ніколи не використовуй Computer Use, CUA або іншу UI-автоматизацію для керування комп'ютером, грою, браузером чи будь-якою програмою без окремого прямого дозволу користувача в поточному повідомленні.
- Слова «дивись», «подивись», «перевір», «що на екрані» або наданий скриншот дозволяють лише пасивний огляд. Вони не дозволяють активувати вікно, змінювати фокус, рухати курсор, натискати клавіші, клацати, вводити текст, прокручувати чи виконувати команди.
- Перед будь-якою дією через UI спочатку опиши конкретну заплановану дію та отримай явне підтвердження користувача. Попередній дозвіл не переноситься на наступні дії або повідомлення.
- Якщо прямого дозволу немає, попроси користувача виконати потрібну дію самостійно та працюй лише з наданим результатом або файлами.
